# Sample Data

This directory is reserved for synthetic or anonymized data used to demonstrate the reporting workflow.

## Data Privacy

No production, customer, employee, or confidential SAP system data is included in this repository.

The original project used SAP system data during development. Since this GitHub repository is public, actual business/customer data should not be published.

## Future Sample Data

If sample data is added in the future, it should be:

- Synthetic data created for demonstration purposes, or
- Properly anonymized data with no personally identifiable or confidential information.

Possible fields may include:

| Field | Description |
|---|---|
| VBELN | Sales document number |
| POSNR | Item number |
| KUNNR | Customer number |
| NAME1 | Customer name |
| MATNR | Material number |
| KWMENG | Order quantity |
| NETWR | Net sales amount |
| WAERK | Currency |
| ERDAT | Document date |
| VKORG | Sales organization |

No real customer or production data should be uploaded.
